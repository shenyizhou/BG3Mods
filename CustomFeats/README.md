# CustomFeats - 自定义专长模组

## 简介
这是一个为《博德之门3》创建的自定义专长模组，添加了新的专长选项。

## 专长列表

### 蛮力 (Brute Force)
**效果：**
- 如果你的力量属性低于21，则提升至21
- 10级时，如果你的力量属性低于26，则提升至26
- 20级时，如果你的力量属性低于31，则提升至31

**说明：**
这个专长让角色的原始体力超越常人极限，随着等级提升获得更强的力量加成。

### 辕门射戟 (Gate Archery)
**效果：**
- 远程武器攻击造成额外的力量调整值物理伤害

**说明：**
传说中吕布辕门射戟的神技，让你的远程攻击能够运用强大的臂力，增加伤害输出。这个专长特别适合力量型的远程战士。

## 安装方法
1. 将整个 `CustomFeats` 文件夹复制到你的博德之门3模组目录
2. 在游戏中启用该模组
3. 在角色升级时选择"蛮力"或"辕门射戟"专长

## 技术实现
- 使用动态属性检查和等级判断
- 支持中英文本地化
- 兼容博德之门3的专长系统
