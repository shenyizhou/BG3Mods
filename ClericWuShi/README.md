# 武师牧师模组 (ClericWuShi Mod)

## 模组简介

武师是一个为《博德之门3》设计的牧师子职业模组，专注于防护和生存能力。该模组为牧师职业添加了"武师"子职业，让玩家能够体验到强大的防护技能和不屈的战斗意志。

**作者**: 沈浪  
**版本**: 1.0  
**类型**: 职业扩展模组

## 核心特色

### 🛡️ 防护体系
武师专精于各种防护技能，拥有强大的生存能力：

#### 1级特性：重甲熟练度
- 获得重甲熟练度，提升防御能力

#### 3级特性：金钟罩
- **金钟罩**：范围防护技能，为9米半径内的所有友方单位提供对所有伤害类型的抗性
- 消耗：1个行动点 + 1个1级法术位
- 持续时间：600回合（约10分钟）

#### 5级特性：铁布衫
- **铁布衫**：范围防护技能，为9米半径内的所有友方单位提供：
  - 对穿刺、挥砍、钝击、力场伤害具有抗性
  - 免疫昏迷和倒地状态
  - 濒死保护：当受到致命伤害时，触发防死效果，生命值保持在1点
- 消耗：1个行动点 + 1个1级法术位
- 持续时间：600回合（约10分钟）

#### 7级特性：金刚不坏神功
- **金刚不坏神功**：强化版范围防护技能
- 消耗：1个行动点 + 1个2级法术位
- 效果：为9米半径内的所有友方单位提供：
  - 对所有伤害类型的抗性
  - 最大生命值增加2d10点
  - 每回合恢复2d10点生命值
- 持续时间：600回合（约10分钟）

#### 10级特性：不灭金身
- **不灭金身**：终极反应技能
- 触发条件：生命值低于50%时自动激活
- 消耗：1个反应行动点
- 效果：
  - 提供强大的伤害加成
  - 免疫多种负面状态
  - 技能结束时会施加力竭状态作为代价"解离术"）
  - 当受到足以致命的伤害时，自动保留1点生命值（效果触发后法术结束）
- **类型**: 光环技能（无需专注）

#### 7级 - 金钟罩强化
- **效果**: 金钟罩额外获得强化
- **功能**: 
  - 增加2d10生命值上限
  - 每回合开始时恢复2d10生命值
- **类型**: 被动强化

#### 10级 - 金刚不坏神功
- **效果**: 反应动作技能
- **触发条件**: 生命值低于50%时可以通过一次反应行动来使用
- **功能**: 
  - 恢复满所有生命值
  - 攻击/力场伤害获得体质调整值加值
  - 期间无法施展或专注于法术
  - 状态结束后获得力竭
- **限制**: 短休只能使用一次

## 设计理念

武师子职业的设计理念是打造一个极具生存能力的牧师变体：

1. **团队防护**: 金钟罩提供大范围的团队保护
2. **持续防御**: 铁布衫提供持续的伤害减免和防死保护
3. **自我恢复**: 强化的金钟罩提供持续的生命恢复
4. **绝境反击**: 金刚不坏神功在危急时刻提供强大的生存和战斗能力

## 安装方法

1. 将模组文件夹复制到游戏的Mods目录
2. 启动游戏并在模组管理器中启用该模组
3. 创建新角色时选择牧师职业，在3级时可选择武师子职业

## 兼容性

- 兼容博德之门3最新版本
- 可与其他职业模组同时使用
- 不会影响原版游戏平衡
