# 武师牧师模组安装指南

## 系统要求

- 博德之门3 (Baldur's Gate 3) 最新版本
- 支持模组的游戏版本
- 足够的存储空间（约10MB）

## 安装步骤

### 1. 下载模组

确保您已经下载了完整的 `ClericWuShi` 模组文件夹。

### 2. 定位游戏模组目录

根据您的操作系统，找到博德之门3的模组目录：

**Windows:**
```
%USERPROFILE%\AppData\Local\Larian Studios\Baldur's Gate 3\Mods
```

**Mac:**
```
~/Library/Application Support/Larian Studios/Baldur's Gate 3/Mods
```

**Linux:**
```
~/.local/share/larian-studios/Baldur's Gate 3/Mods
```

### 3. 复制模组文件

1. 将整个 `ClericWuShi` 文件夹复制到上述模组目录中
2. 确保文件夹结构完整，包含以下目录：
   - `Mods/ClericWuShi/`
   - `Public/ClericWuShi/`
   - `Localization/`

### 4. 启用模组

1. 启动博德之门3
2. 在主菜单中选择"模组"
3. 找到"武师牧师 (ClericWuShi)"模组
4. 点击启用
5. 确认模组加载顺序正确

## 使用指南

### 创建武师角色

1. 开始新游戏或创建新角色
2. 选择"牧师"职业
3. 在3级时，选择"武师"子职业
4. 享受独特的防护技能体验！

### 技能使用说明

#### 3级 - 金钟罩
- **类型**: 主动技能
- **消耗**: 1级法术位 + 1行动点
- **范围**: 大范围（9米半径）
- **效果**: 为范围内所有队友提供全伤害抗性
- **持续时间**: 600回合（10分钟）

#### 5级 - 铁布衫
- **类型**: 被动光环
- **消耗**: 无（自动激活）
- **效果**: 
  - 对物理伤害和力场伤害抗性
  - 免疫昏迷和倒地
  - 防死保护（触发后效果结束）

#### 7级 - 金钟罩强化
- **类型**: 被动强化
- **效果**: 
  - 生命值上限增加2d10
  - 每回合开始恢复2d10生命值

#### 10级 - 金刚不坏神功
- **类型**: 反应技能
- **触发条件**: 生命值低于50%
- **消耗**: 1反应点
- **限制**: 短休1次
- **效果**: 
  - 立即恢复满血
  - 攻击和力场伤害获得体质加值
  - 无法施法或专注
  - 结束后获得力竭

## 故障排除

### 常见问题

**Q: 模组无法加载？**
A: 检查文件夹结构是否正确，确保所有必要文件都在正确位置。

**Q: 技能显示为英文？**
A: 确保 `Localization/Chinese/` 目录下的本地化文件存在且完整。

**Q: 技能效果不正常？**
A: 检查是否有其他模组冲突，尝试调整模组加载顺序。

**Q: 游戏崩溃？**
A: 暂时禁用模组，确认是否为模组冲突导致，检查游戏版本兼容性。

### 兼容性

- ✅ 与大多数其他职业模组兼容
- ✅ 与UI增强模组兼容
- ⚠️ 可能与修改牧师基础机制的模组冲突
- ❌ 不兼容修改相同UUID的模组

## 卸载模组

1. 在游戏中禁用模组
2. 删除 `Mods` 目录下的 `ClericWuShi` 文件夹
3. 重启游戏

**注意**: 卸载模组前请备份存档，已创建的武师角色可能无法正常加载。
