# 武侠模组 (KungFuMaster Mod)

## 模组简介

武侠是一个为《博德之门3》设计的独立职业模组，融合了中国武侠文化元素。该模组提供了一个全新的"武侠"职业，让玩家能够体验到独特的武侠风格战斗和技能系统。经过平衡性调整和特色化改造，现在专注于提供真正独特的武侠体验。

**作者**: 沈浪
**版本**: 4.0 - 武侠版
**类型**: 独立职业模组

## 核心特色

### 🥋 武功体系
模组包含四大核心武功门类，每类都有独特的被动技能和战斗效果：

1. **内功心法** - 内力修炼与身体强化
   - 易筋经：基础内功强化
   - 洗髓经：毒素抗性与体质提升
   - 冰心诀：专注维持与心境平和
   - 天蚕功：生命恢复与护甲强化
   - 不死印法：死亡豁免优势
   - 神照经：治疗效果增强
   - 太玄经：终极内功修为

2. **外功技能** - 战斗技巧与攻击手段
   - 五雷天心诀：雷电攻击与静电效果
   - 太极化劲：以柔克刚的防御反击
   - 连环夺命：连续攻击技巧

3. **轻功身法** - 移动与闪避能力
   - 梯云纵：跳跃与移动增强
   - 一苇渡江：地形适应与移动自由
   - 凌波微步：闪避与防护能力
   - 飞絮轻烟功：轻身术与隐匿
   - 飞燕回风：敏捷优势时的致命攻击

4. **软功技艺** - 感知与技巧
   - 明目功：视觉增强与感知提升
   - 左右手互搏术：双持战斗技巧

### 🎯 设计理念

**独特性优先**: 所有技能都具有独特的武侠机制，不再是原版游戏技能的简单重命名
**平衡性保证**: 经过系统性平衡调整，确保强度合理，不破坏游戏平衡
**武侠特色**: 专注于体现真正的武侠文化内涵和战斗风格
**精简高效**: 删除冗余内容，每个技能都有明确的作用和特色

## 职业特性

### 基础属性
- **生命骰**: d8
- **主要属性**: 感知

- **气力骰子(SuperiorityDice)**: 主要资源，从1级开始获得，每级增加，用于施展各种武功技能

- **武道精华(MartialEssence)**: 16级获得，用于增强战斗技能

### 气力骰子升级机制

气力骰子不仅数量会随等级增长，其面数也会在特定等级时升级：

**骰面升级规律：**
- **1-9级**: 1d8（基础阶段）
- **10级**: 升级为1d10（小成境界）
- **12级**: 升级为1d12（大成境界）
- **14级**: 升级为1d14（精通境界）
- **16级**: 升级为1d16（宗师境界）
- **20级**: 升级为1d20（巅峰境界）

**数量增长规律：**
- **3级**: 基础获得6个气力骰子
- **奇数级别**（5、7、9、11、13、15、17、19级）：额外增加1个气力骰子
- **偶数级别**（4、6、8、10、12、14、16、18、20级）：数量保持不变
- **最终在20级时拥有14个1d20的气力骰子**

这种设计体现了武功修炼的渐进性，随着等级提升，内力运用更加精纯，气力骰子的威力也随之增强。

### 博德之门3原版武僧气点消耗对比

#### 散打宗(Open Hand)
- **疾风连击(Flurry of Blows)**: 1个气点 - 附赠动作进行2次徒手攻击
- **震慑拳(Stunning Strike)**: 1个气点 - 徒手攻击或武僧武器攻击时可选择震慑目标
- **坚强防御(Patient Defense)**: 1个气点 - 附赠动作进行闪避
- **飞檐走壁(Step of the Wind)**: 1个气点 - 附赠动作冲刺或脱离

#### 暗影宗(Way of Shadow)
- **暗影步(Shadow Step)**: 2个气点 - 传送到阴影区域
- **暗影分身(Shadow Clone)**: 3个气点 - 创造暗影分身
- **暗影潜行(Pass without Trace)**: 2个气点 - 团队隐匿增强

#### 四象宗(Way of the Four Elements)
- **1环法术**: 2个气点 - 如燃烧之手、雷鸣波等
- **2环法术**: 3个气点 - 如蛛网术、火球术等
- **3环法术**: 4个气点 - 如火球术等高级法术
- **水火交融**: 短休时恢复气点

#### 醉拳宗(Way of the Drunken Master)
- **醉拳技巧**: 1个气点 - 附赠动作进行2次攻击并获得移动加成
- **醉酒打击**: 1个气点 - 攻击并可能使目标醉酒
- **发人深醒**: 1个气点 - 对醉酒目标造成额外心灵伤害
- **借力打力**: 1个气点 - 反应动作进行反击
- **醉汉机运**: 2个气点 - 消除劣势

### 设计对比分析

**武侠模组特点**:
- 气力骰子消耗相对保守，仅有1个技能消耗气力骰子
- 专注于反击机制，体现太极以柔克刚的理念
- 气力骰子总量较高，但消耗技能较少，更多依赖被动技能

**原版武僧特点**:
- 气点消耗技能丰富，几乎所有主动技能都需要气点
- 气点总量较低(最高13个)，但有多种消耗方式
- 不同子职业有不同的气点使用策略

**平衡性考虑**:
- 武侠模组通过减少气力骰子消耗技能数量，避免了资源管理的复杂性
- 高气力骰子总量配合少量消耗技能，确保玩家可以频繁使用核心技能
- 更多依赖被动技能和状态效果，减少了微操作需求

## 武功门类系统

武侠拥有七大武功门类，每类都有独特的技能和效果：

### 七大武功门类
1. **医药(YiYao)** - 治疗与恢复技能
2. **硬功(YingGong)** - 防御与抗性技能
3. **软功(RuanGong)** - 感知与技巧技能
4. **轻功(QingGong)** - 移动与闪避技能
5. **内功(NeiGong)** - 内力修炼与强化技能
6. **外功(WaiGong)** - 攻击与战斗技能
7. **拆招(ChaiZhao)** - 反击与化解技能（已精简，仅保留太极功）

### 技能获得方式
- **1级**: 从七大门类中各选择1个技能
- **3级**: 从七大门类中再各选择1个技能
- **10级**: 选择1个增强辅助技能
- **12级**: 选择1个增强反应技能
- **14级**: 选择1个增强状态技能
- **16级**: 选择2个增强战斗技能

## 安装说明

1. 下载模组文件
2. 将模组文件夹复制到游戏的Mods目录
3. 启动游戏并在模组管理器中启用"KungFuMaster"
4. 创建新角色时选择牧师职业，然后选择"武功领域"子职业

## 使用建议

### 属性分配
- **主要属性**: 感知（影响法术效果和豁免DC）
- **次要属性**: 体质（提升生存能力和气力骰子恢复）
- **第三属性**: 力量或敏捷（根据武功风格选择）

### 战斗策略
- 前期依靠重甲和基础武功进行近战，合理分配气力骰子
- 中期开始组合不同武功类型获得协同效果，利用特殊资源
- 后期掌握增强技能，成为全能武功大师

### 武功搭配建议
- **防御型**: 硬功 + 医药 + 内功（重甲坦克流）
- **敏捷型**: 轻功 + 软功 + 拆招（灵活战士流）
- **攻击型**: 外功 + 内功 + 轻功（输出核心流）
- **平衡型**: 各类武功均衡发展（全能武者流）

**注意**: 拆招门类已精简为仅包含太极功，专注于反击机制
