# 武功僧侣模组 (KungFuMonk Mod)

## 模组简介

武功僧侣是一个为《博德之门3》设计的独立职业模组，融合了中国武侠文化元素。该模组提供了一个全新的"武功僧侣"职业，让玩家能够体验到独特的武侠风格战斗和技能系统。经过平衡性调整和特色化改造，现在专注于提供真正独特的武侠体验。

**作者**: 沈浪  
**版本**: 3.1 - 气点资源版  
**类型**: 独立职业模组

## 核心特色

### 🥋 武功体系
模组包含四大核心武功门类，每类都有独特的被动技能和战斗效果：

1. **内功心法** - 内力修炼与身体强化
   - 易筋经：基础内功强化
   - 洗髓经：毒素抗性与体质提升
   - 冰心诀：专注维持与心境平和
   - 天蚕功：生命恢复与护甲强化
   - 不死印法：死亡豁免优势
   - 神照经：治疗效果增强
   - 太玄经：终极内功修为

2. **外功技能** - 战斗技巧与攻击手段
   - 五雷天心诀：雷电攻击与静电效果
   - 太极化劲：以柔克刚的防御反击
   - 连环夺命：连续攻击技巧

3. **轻功身法** - 移动与闪避能力
   - 梯云纵：跳跃与移动增强
   - 一苇渡江：地形适应与移动自由
   - 凌波微步：闪避与防护能力
   - 飞絮轻烟功：轻身术与隐匿
   - 飞燕回风：敏捷优势时的致命攻击

4. **软功技艺** - 感知与技巧
   - 明目功：视觉增强与感知提升
   - 左右手互搏术：双持战斗技巧

### 🎯 设计理念

**独特性优先**: 所有技能都具有独特的武侠机制，不再是原版游戏技能的简单重命名
**平衡性保证**: 经过系统性平衡调整，确保强度合理，不破坏游戏平衡
**武侠特色**: 专注于体现真正的武侠文化内涵和战斗风格
**精简高效**: 删除冗余内容，每个技能都有明确的作用和特色

## 职业特性

### 基础属性
- **生命骰**: d8
- **主要属性**: 感知
- **熟练项**: 轻甲、中甲、重甲、盾牌、简单武器、晨星、连枷
- **豁免熟练**: 感知、魅力

### 资源系统
- **气点(KiPoint)**: 主要资源，从1级开始获得5个，每级增加，用于施展各种武功技能
- **凝聚气(ConcentratedKi)**: 10级获得，用于增强辅助技能
- **真气池(TrueQiPool)**: 12级获得，用于增强反应技能
- **元素刃资源(ElementalBladeResource)**: 14级获得，用于增强状态技能
- **武道精华(MartialEssence)**: 16级获得，用于增强战斗技能
- **法术位**: 标准牧师法术系统

## 武功门类系统

武功僧侣拥有七大武功门类，每类都有独特的技能和效果：

### 七大武功门类
1. **医药(YiYao)** - 治疗与恢复技能
2. **硬功(YingGong)** - 防御与抗性技能  
3. **软功(RuanGong)** - 感知与技巧技能
4. **轻功(QingGong)** - 移动与闪避技能
5. **内功(NeiGong)** - 内力修炼与强化技能
6. **外功(WaiGong)** - 攻击与战斗技能
7. **拆招(ChaiZhao)** - 反击与化解技能

### 技能获得方式
- **1级**: 从七大门类中各选择1个技能
- **3级**: 从七大门类中再各选择1个技能
- **10级**: 选择1个增强辅助技能
- **12级**: 选择1个增强反应技能
- **14级**: 选择1个增强状态技能
- **16级**: 选择2个增强战斗技能

## 安装说明

1. 下载模组文件
2. 将模组文件夹复制到游戏的Mods目录
3. 启动游戏并在模组管理器中启用"KungFuMonk"
4. 创建新角色时选择牧师职业，然后选择"武功领域"子职业

## 使用建议

### 属性分配
- **主要属性**: 感知（影响法术效果和豁免DC）
- **次要属性**: 体质（提升生存能力和气点恢复）
- **第三属性**: 力量或敏捷（根据武功风格选择）

### 战斗策略
- 前期依靠重甲和基础武功进行近战，合理分配气点
- 中期开始组合不同武功类型获得协同效果，利用特殊资源
- 后期掌握增强技能，成为全能武功大师

### 武功搭配建议
- **防御型**: 硬功 + 医药 + 内功（重甲坦克流）
- **敏捷型**: 轻功 + 软功 + 拆招（灵活战士流）
- **攻击型**: 外功 + 拆招 + 内功（输出核心流）
- **平衡型**: 各类武功均衡发展（全能武者流）
