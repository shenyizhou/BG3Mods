# 战士武侠子职业 (Fighter Wu Xia Subclass)

## 概述

这个模组为《博德之门3》的战士职业添加了一个全新的子职业：**武侠**。武侠融合了东方武学的精髓，拥有独特的内功心法和外功招式。

## 职业特性

### 3级 - 大金刚神力
- **效果**: 攻击和力场伤害获得等同于力量调整值的额外伤害加值
- **描述**: 运用内力增强攻击威力，让每一击都蕴含强大的内功

### 5级 - 鹰眼
- **效果**:
  - 获得60尺黑暗视觉
  - 免疫失明状态
  - 远程武器射程增加50%
- **描述**: 拥有敏锐的视觉和感知能力，如鹰眼般锐利

### 7级 - 六脉神剑
- **效果**: 解锁传说中的六脉神剑技能组合
- **包含技能**:
  - **少商剑**: 凌厉剑气，造成2d10力场伤害
  - **商阳剑**: 精准剑气，造成3d6力场伤害
  - **中冲剑**: 范围剑气，对1.5米范围内敌人造成1d10力场伤害
  - **关冲剑**: 强力剑气，造成1d10力场伤害并击退3米，可能击倒
  - **少冲剑**: 迅捷剑气，造成1d10力场伤害并获得下回合先攻优势
  - **少泽剑**: 破防剑气，造成1d10力场伤害并施加易伤状态
  - **六脉神剑**: 终极奥义，同时发射六道剑气，总计6d10+3d6力场伤害

## 设计理念

- **武侠风格**: 融合了传统武侠小说中的内功心法和剑法绝技
- **平衡性**: 所有技能都经过精心设计，确保不会破坏游戏平衡
- **独特性**: 与功夫大师的六脉神剑相比，使用固定伤害而非气力骰子系统
- **成长性**: 随着等级提升逐步解锁更强大的能力

## 安装方法

1. 将整个 `FighterWuXia` 文件夹复制到博德之门3的模组目录
2. 在游戏中启用该模组
3. 创建战士角色时选择"武侠"子职业

## 兼容性

- 兼容博德之门3最新版本
- 可与其他职业模组同时使用
- 不会影响原版游戏内容
