# 武功门派武僧 (KungFuMonk) - 博德之门3模组

## 模组简介

**武功门派武僧**是一个基于《博德之门3》的武僧子职业模组，将传统的东方武学与D&D武僧职业完美结合。玩家可以选择不同的武功流派，修炼各种神奇的武功技能，体验独特的东方武侠风格。

## 核心特色

### 🔥 气点系统
- 使用**气点**作为核心资源，替代传统的法术位
- 气点随等级提升而增加，用于施展各种武功技能
- 完美融合武僧的Ki点系统

### ⚔️ 七大武功流派

#### 1. 医药流派
- **黄帝内经**：精通医术，治疗盟友
- 获得强力的治疗和辅助技能

#### 2. 硬功流派
- **金刚不坏神功**：强化防御，减少物理伤害
- **大金刚神力**：增强攻击力和伤害输出

#### 3. 软功流派
- **明目功**：获得超凡感知，免疫多种负面状态
- **神机百变**：掌握伪装术
- **左右手互搏术**：双武器战斗专精

#### 4. 轻功流派
- **梯云纵**：超凡跳跃能力
- **一苇渡江**：极速移动，免疫束缚
- **凌波微步**：闪避专精，免疫控制
- **飞絮轻烟功**：隐身和传送技能

#### 5. 内功流派
- **易筋经**：免疫疾病和毒素
- **洗髓经**：全属性提升
- **天蚕功**：受伤时反击和恢复
- **不死印法**：死亡豁免加成
- **神照经**：复活技能
- **太玄经**：重击后恢复移动

#### 6. 外功流派
- **独孤九剑**：逐级获得各种伤害抗性
- **五形拳**：模拟动物形态的战斗技巧
- **五雷天心诀**：掌控雷电之力

#### 7. 拆招流派
- **太极拳**：以柔克刚的防御技巧
- **斗转星移**：反弹敌人攻击
- **乾坤大挪移**：转移和重定向伤害

## 等级进阶

### 武僧特色能力
- **1级**：无甲防御，初始3个气点，选择武功流派
- **2级**：无甲移动，增加气点
- **3级**：拨挡飞弹，继续选择武功
- **4级**：轻身坠，气点增加
- **5级**：额外攻击，更多气点
- **6级**：真气驻拳，武器攻击魔法化
- **7级**：反射闪避，敏捷豁免优势
- **8级**：心如止水，魅惑和恐慌免疫
- **9级**：增强移动，更快的移动速度
- **10级**：毒素免疫，完全免疫毒素
- **11级及以上**：持续获得气点，解锁高级武功

## 安装方法

1. 下载模组文件
2. 将整个文件夹复制到博德之门3的Mods目录
3. 启动游戏，在模组管理器中启用"KungFuMonk"
4. 创建角色时选择武僧职业，然后选择"武功门派"子职业

## 游戏建议

### 属性分配
- **主属性**：智慧（影响气点和武僧能力）
- **次要属性**：体质（生存能力）、敏捷（护甲等级和先攻）
- **推荐种族**：人类、精灵、半精灵、龙裔

### 武功选择策略
- **新手推荐**：医药+硬功组合，既能治疗又能抗伤害
- **输出流**：外功+拆招组合，高伤害和反击能力
- **敏捷流**：轻功+软功组合，极高机动性和闪避
- **平衡流**：内功为核心，搭配其他流派

## 常见问题

**Q: 这个模组与原版武僧有什么区别？**
A: 本模组在武僧基础上添加了丰富的东方武学元素，提供七大武功流派选择，每个流派都有独特的技能和玩法。

**Q: 气点系统如何工作？**
A: 气点是本模组的核心资源，用于施展武功技能。随着等级提升，你会获得更多气点，可以使用更强大的武功。

**Q: 可以同时学习多个流派吗？**
A: 可以！每次升级时都可以选择不同流派的武功，建议根据你的战斗风格来搭配。

**Q: 模组稳定性如何？**
A: 本模组基于成熟的KungFuCleric模组改编，经过充分测试，稳定性良好。
