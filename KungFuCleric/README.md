# 武功牧师模组 (KungFuCleric Mod)

## 模组简介

武功牧师是一个为《博德之门3》设计的牧师子职业模组，融合了中国武侠文化元素。该模组为牧师职业添加了"武功领域"子职业，让玩家能够体验到独特的武侠风格战斗和技能系统。

**作者**: 沈浪  
**版本**: 1.0  
**类型**: 职业扩展模组

## 核心特色

### 🥋 武功体系
模组包含七大武功门类，每类都有独特的被动技能和战斗效果：

1. **医药** - 治疗和恢复能力
   - 黄帝内经：提升治疗效果
   - 神照经：增强恢复能力

2. **硬功** - 防御和抗性能力
   - 金刚不坏神功：提升物理抗性
   - 大金刚神力：增强力量属性

3. **软功** - 灵活性和技巧
   - 明目功：提升感知能力
   - 神机百变：增加技能多样性
   - 左右手互搏术：特殊战斗技巧

4. **轻功** - 移动和敏捷
   - 梯云纵：提升移动速度
   - 一苇渡江：水上行走能力
   - 凌波微步：闪避能力
   - 飞絮轻烟功：轻身术

5. **内功** - 内力修炼
   - 易筋经：基础内功
   - 洗髓经：高级内功
   - 天蚕功：特殊内功
   - 不死印法：生存能力
   - 太玄经：终极内功

6. **外功** - 外在力量
   - 五雷天心诀：雷电攻击

7. **拆招** - 战术技巧
   - 太极拳：以柔克刚
   - 斗转星移：反击技能
   - 乾坤大挪移：力量转移

### ⚔️ 独孤九剑
传说中的剑法，包含九种破解技巧：
- 独孤剑法：基础剑术
- 破剑式：破解剑术
- 破枪式：破解枪法
- 破掌式：破解掌法
- 破弓式：破解远程
- 破气式：破解内功
- 破阴式：破解阴招
- 总诀式：综合运用

### 🐅 五形拳
模仿动物形态的拳法：
- 虎形：力量型攻击
- 鹤形：优雅防御
- 龙形：威猛攻击
- 蛇形：灵活攻击
- 鹰形：精准攻击
- 五形合一：组合技能
- 形意转换：形态切换

## 职业特性

### 基础属性
- **生命骰**: d8
- **主要属性**: 感知
- **熟练项**: 重甲、盾牌、简单武器
- **豁免熟练**: 感知、魅力

### 资源系统
- **优势骰**: 从1级开始获得，用于各种武功技能
- **内力点**: 特殊资源，用于施展高级武功

## 安装说明

1. 下载模组文件
2. 将模组文件夹复制到游戏的Mods目录
3. 启动游戏并在模组管理器中启用"KungFuCleric"
4. 创建新角色时选择牧师职业，然后选择"武功领域"子职业

## 使用建议

### 属性分配
- **主要属性**: 感知（影响法术效果和豁免DC）
- **次要属性**: 体质（提升生存能力）
- **第三属性**: 力量或敏捷（根据战斗风格选择）

### 战斗策略
- 前期依靠重甲和基础武功进行近战
- 中期开始组合不同武功类型获得协同效果
- 后期掌握独孤九剑和五形拳，成为全能战士

### 武功搭配建议
- **防御型**: 硬功 + 医药 + 内功
- **敏捷型**: 轻功 + 软功 + 拆招
- **平衡型**: 各类武功均衡发展

## 兼容性

- 兼容大部分其他职业和种族模组
- 建议与武器扩展模组一起使用以获得更好体验
- 支持多人游戏
