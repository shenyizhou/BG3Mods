# RogueYouYing - 幽影游荡者子职业

## 模组简介

**RogueYouYing** 是一个为《博德之门3》添加全新游荡者子职业"幽影"的模组。这个子职业专注于阴影操控和隐身技巧，为玩家提供独特的战术体验。

## 核心特性

### 🌟 主要能力
- **3级 - 幽影潜行**：获得永久隐身开关技能，可随时进入高级隐身状态
- **7级 - 阴影移动**：隐身时移动速度提升，持续时间延长
- **10级 - 阴影抗性**：获得对死灵和心灵伤害的抗性
- **15级 - 阴影打击**：隐身状态下可进行一次攻击而不解除隐身
- **18级 - 阴影大师**：隐身时所有攻击获得优势，每次长休息恢复法术位

### ⚔️ 战术优势
- 开关式隐身机制，无冷却时间限制
- 隐身期间获得移动速度加成
- 敏捷豁免检定获得优势
- 高级隐身状态，难以被发现
- 攻击或施法会自动解除隐身（平衡性设计）

## 安装说明

1. 将整个 `RogueYouYing` 文件夹复制到你的BG3模组目录
2. 使用BG3模组管理器启用此模组
3. 启动游戏，创建游荡者角色
4. 在3级时选择"幽影"子职业

## 使用指南

### 创建角色
1. 选择游荡者作为主职业
2. 正常进行角色创建流程
3. 达到3级时，在子职业选择界面选择"幽影"

### 技能使用
1. 获得"幽影潜行"技能后，将其添加到快捷栏
2. 点击技能图标激活隐身状态
3. 再次点击可关闭隐身状态
4. 注意：攻击或施法会自动解除隐身

## 平衡性说明

为了保持游戏平衡，幽影潜行技能具有以下限制：
- 攻击或施法会立即解除隐身
- 受到伤害时可能被发现
- 在明亮光线下隐身效果可能减弱
- 每次战斗使用次数有限制
